Features

Everything between “downloaded” and “printed”.

One place for the models, the spools, the printers and the spare parts.

A library that indexes itself

Point Printventory at your folders and it builds a searchable library with thumbnails, tags, designers, notes and source URLs, without moving a single file.

  • Folder-tree explorer, grid, list and preview views
  • Instant search and filters across tens of thousands of models
  • Duplicate detection by content hash
  • 3D Preview Studio with lighting, materials and 3MF part picking

Print lifecycle

Want → Queued → Printing → Printed (or Failed), with a full log.

  • Date, quantity, notes and filament for every print
  • Sort by last printed or print count
  • “Printed ×N” badges for reprints

Filament catalog & Spoolman

Build a catalog, assign spools to models and filter the library by material or color. If you already run Spoolman, Printventory can pull your catalog from it.

Printers & parts stock

Save your printers with maintenance logs and reminders, and find them on the network (Klipper, PrusaLink, Bambu). Track screws, bearings and other hardware, then deduct them automatically when you log a print.

AI tagging & MCP

Get tag suggestions from model metadata with the AI provider you choose. Agents like Claude Desktop and Cursor can query your library over MCP.

  • Model files never leave your machine

Docker, NAS & phone

Run it in server mode on Synology, Unraid and other NAS boxes, with HTTPS. Install it on your phone as a PWA.

  • Official Docker Hub image

Browser extension & organizer

Printventory Watcher queues model pages while the app is closed. Organize Library copies files into a structure you choose, with verified moves.

  • OBJ
